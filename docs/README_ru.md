# Документация — с чего начать

Фреймворк для задач на потоковых графах — сетях, где перемещаемые единицы
(commodity) движутся между узлами (facility); первый и пока единственный
сценарий — система проката велосипедов Citi Bike в Нью-Йорке. Эта страница —
карта `docs/`:

- Запустить — иди в [Getting Started](#getting-started).
- Понять — иди в [Key Components](#key-components).
- Изменить — иди в [How-to](#how-to).
- Найти точный контракт — иди в [Reference](#reference).

## Getting Started

Учебные маршруты: выполняй шаги и сверяйся с ожидаемым выводом.

- [installation.md](getting-started/installation.md) — установить пакет и
  скачать месяц реальных поездок; Docker и OSRM — ссылками.
- [quickstart.md](getting-started/quickstart.md) — от чистого клона до
  первого журнала flow-событий за несколько минут, на синтетическом
  сценарии без скачивания данных.
- [ui.md](getting-started/ui.md) — создать первый сохранённый запуск и
  пройтись по страницам веб-интерфейса.

## Key Components

Объяснения: как устроена каждая часть и почему она сделана именно так —
без пошаговых инструкций. Сначала прочитай первую страницу; на неё
опирается всё остальное.

- [overview.md](key-components/overview.md) — пять понятий (период, спрос,
  инвентарь станции, журнал flow-событий, артефакт запуска), затем система
  в диаграммах на трёх масштабах, в конце — полная карта модулей.
- [data-model.md](key-components/data-model.md) — загрузчики: от сырого CSV
  поездок до входных таблиц симулятора.
- [flow-journal.md](key-components/flow-journal.md) — библиотека журнала
  (`gbp/model/`): таблица, в которую строки только добавляются и которая
  хранит всю историю запуска.
- [worked-examples.md](key-components/worked-examples.md) — самые маленькие
  настоящие таблицы журнала, по одному сценарию; каждую таблицу заново
  прогоняет тест.
- [simulation-engine.md](key-components/simulation-engine.md) — как работает
  один запуск: цикл по периодам, его фазы, инварианты.
- [rebalancing.md](key-components/rebalancing.md) — как симулятор перевозит
  велосипеды грузовиками ночью.
- [ml-toolkit.md](key-components/ml-toolkit.md) — конвейер прогноза спроса:
  обучение, проверка на прошлых месяцах, выбор модели-чемпиона, мониторинг.
- [visualization.md](key-components/visualization.md) — путь от завершённого
  запуска до экрана: раннер, артефакт запуска, приложение на Streamlit.

## Scenarios

Первый сценарий — система Citi Bike в Нью-Йорке. Его каноническая форма —
два запуска, каждый в своём ноутбуке:

- [citibike.md](scenarios/citibike.md) — сценарий от начала до конца:
  задача, соответствие сущностям, данные, запускаемый минимальный пример,
  запуски и как читать результаты.
- [test_pipeline.ipynb](../notebooks/test_pipeline.ipynb) — базовое
  воспроизведение одного месяца истории.
- [forecast_pipeline.ipynb](../notebooks/forecast_pipeline.ipynb) — тот же
  запуск на прогнозном спросе.

## How-to

Рецепты, одна задача на страницу: шаги, настоящие команды, ожидаемый
результат. Новый рецепт появляется, когда одна и та же задача возникла
дважды.

- [change-the-demand.md](how-to/change-the-demand.md) — изменить масштаб
  спроса или проиграть другой месяц.
- [run-on-a-forecast.md](how-to/run-on-a-forecast.md) — запустить симулятор
  на сохранённом прогнозе вместо истории.
- [add-a-table-to-the-run-artifact.md](how-to/add-a-table-to-the-run-artifact.md)
  — добавить заранее посчитанную таблицу в каждый сохраняемый запуск.
- [debug-an-invariant-violation.md](how-to/debug-an-invariant-violation.md)
  — понять, какой инвариант (I1–I5) нарушен и какие строки журнала смотреть.
- [set-up-osrm.md](how-to/set-up-osrm.md) — настроить необязательный
  маршрутный сервер на дорожном графе.

## Decisions

Проектные решения, которые затрагивают несколько модулей, по одной короткой
записи; решение внутри одного модуля лежит в секции «Why It Is Built This
Way» его страницы.

- [journal-as-source-of-truth.md](decisions/journal-as-source-of-truth.md)
  — запуск хранится как журнал, в который строки только добавляются, а не
  как одна редактируемая таблица состояния.
- [sizing-run.md](decisions/sizing-run.md) — начальный инвентарь и ёмкости
  доков измеряются отдельным запуском (sizing run), а не загружаются из
  файла.
- [forecast-replaces-only-demand.md](decisions/forecast-replaces-only-demand.md)
  — запуск на прогнозе заменяет только таблицу спроса базового
  воспроизведения.

## Остальное в docs/

`plans/` — планы текущей работы; `reports/` — сохранённые отчёты об оценке
и ревью; `method/` — личные заметки автора о методе работы: чтение для
интересующихся, не часть маршрута выше. Документы — на английском;
каноническая версия этой страницы — [README.md](README.md), пара держится
синхронной.
