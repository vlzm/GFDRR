# Длительность и расстояние поездки

Как в коде считаются время и расстояние поездки.

**Длительность** задаёт симуляцию (в периодах). **Расстояние в километрах** считается при анализе журнала и в одном месте симуляции: по нему оценивается время плеча перенаправления, если пары нет в OD-матрице. **Квадрат евклидова расстояния по координатам** — только для выбора соседней станции при перенаправлении.

## Длительность

Единица — **период симуляции**. По умолчанию один период = один час (`DEFAULT_PERIOD_LEN` в `gbp/loaders/dataloader_graph.py`).

### Исторические поездки

Из CSV берутся `started_at` и `ended_at`, переводятся в номера периодов через `to_period_id`:

```python
start_period = to_period_id(started_at, t0, period_len)
planned_end_period = to_period_id(ended_at, t0, period_len)
```

Длительность в периодах:

```
duration = planned_end_period - start_period
```

Это целочисленное деление прошедшего времени на интервалы длины `period_len`.

### Симулированные поездки

OD-матрица строится в `flows_to_od_matrix` из пользовательских отправлений исторического журнала:

1. Для каждого отправления: `duration = planned_end_period - start_period`
2. Группировка по `(source_id, planned_target_id, period_id, commodity_category)`
3. Средняя `duration`, округление до целого периода

В `form_potential_trips`:

```python
planned_end_period = period_id + duration
```

где `period_id` — период отправления, `duration` — из OD-матрицы для пары станций.

### Перенаправления

Если велосипед не помещается на станции, `plan_overflow_redirect` планирует новое плечо. Время в пути — `_leg_durations`: средняя `duration` из OD-матрицы для пары `(planned_target_id, realized_target_id)`.

Если пары в истории не было, время оценивается через расстояние и скорость:

```
duration = round(haversine_km(пара) / trip_speed_km_per_period)
```

`trip_speed_km_per_period` — средняя скорость по всем историческим поездкам: суммарное расстояние по дуге большого круга, делённое на суммарное время в пути (`get_trip_speed_km_per_period` в `gbp/loaders/dataloader_graph.py`). Скорость считается по сырым отметкам времени `started_at` и `ended_at`, а не по OD-матрице: там длительности округлены до целых периодов, а большинство поездок короче одного периода, и деление шло бы на почти нулевое время. Поездки с одинаковой станцией старта и финиша, нулевым временем или без координат пропускаются.

При часовом периоде оценка округляется в 0 для любого плеча короче половины часовой скорости (примерно 7 км при обычной скорости велосипеда). Поэтому близкие перенаправления по-прежнему прибывают в том же периоде; лишние периоды получает только плечо до далёкой станции.

### Поля в `get_flows_wide`

После присоединения координат и атрибутов станций:

- `planned_duration = planned_end_period - start_period`
- `realized_duration = realized_end_period - start_period`

## Расстояние

Если пара есть в OD-матрице, время в пути берётся оттуда. Расстояние задаёт время только в запасном расчёте для перенаправления, описанном выше.

### Километры (Haversine)

Расстояние по дуге большого круга между координатами станций: `haversine_km` в `gbp/model/flows.py`, радиус Земли 6371.0088 км. Используется в двух местах:

- Анализ: `get_flows_wide` (`gbp/loaders/dataloader_graph.py`) добавляет `planned_distance_km` (источник → запланированная цель) и `realized_distance_km` (источник → фактическая цель, после перенаправления).
- Симуляция: запасной расчёт времени перенаправления выше и средняя скорость, на которую он делит.

### Ранжирование соседей — только перенаправление

`neighbor_distance_sq` в `gbp/model/flows.py`:

```python
(lat - other_lat) ** 2 + (lng - other_lng) ** 2
```

Выбор ближайшей свободной станции и объяснение перенаправлений (`redirect_neighbor_table`). В журнал как расстояние поездки не записывается.

## Сводка

| Величина | Как считается | В симуляции? |
|----------|---------------|--------------|
| Длительность (периоды) | `planned_end_period - start_period` | Да |
| Время в пути | Средняя `duration` из OD | Да |
| Время перенаправления, пары нет в OD | `round(haversine_km / trip_speed_km_per_period)` | Да |
| Средняя скорость | Сумма км по haversine / сумма времени, по сырым отметкам времени | Да (запасной расчёт) |
| Расстояние (км) | Haversine по lat/lng | Анализ + запасной расчёт |
| Близость соседа | Квадрат расстояния по lat/lng | Только redirect |
