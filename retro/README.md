## Повторяющийся рисунок

Одно и то же ядро переписывалось трижды, каждый раз с новым именем:

`gbp/graph` (март) → `gbp/core` (март–июнь) → `gbp/model` (июнь–сейчас)

Тестовая структура строилась и была снесена целиком один раз
(`tests/unit` + `tests/integration` + `tests/fixtures`, 11 мая), после чего
тесты живут плоским списком в `tests/`.

Система документации строилась и сносилась дважды: `docs/design` +
`docs/story_telling` + `docs/modules` (март–май), затем `docs/design_documents`
(май–июнь), сейчас — `docs/method` + `docs/plans` + `docs/site`.
